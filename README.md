# Iron Lotus — Kizuki Custom

A single-page showcase for **Iron Lotus**, a custom weapon in the Roblox game
*Kizuki*, inspired by *Library of Ruina*. Fiery orange theme with a live fire
background, lore, a design showcase, holder list, title, changelog, a
pose-theme player, and a hidden "burning book" easter egg.

Pages (top nav): **Home · Lore · Design · Holders · Title · Changelog**

## Edit the content
Everything the site shows lives in the `data` object near the top of the
`<script>` in `index.html`: `lore`, `owner`, `contributors`, `holders`,
`tempHolders`, `blacklist`, `stats`, `progress`, `timeline`, and `tracks`.

## View / host
Open `index.html` in a browser. Hosted free via **GitHub Pages**
(Settings → Pages → Source: "GitHub Actions"); every push to `main` redeploys.
